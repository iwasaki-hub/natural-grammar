# Foundation 2 — 「今日の一歩」ホーム画面

## 目的と根拠

[初期デザイン](../design/first-step.md)のホーム画面を、iPhoneで見られる最小のExpo画面として実装する。30日コースの現在位置、今日の学習、学習の手応えを順に表示する。

UIのレビューには [Codex Tips UI設計編](https://github.com/iwasaki-hub/codex-tips/blob/main/docs/UI_DESIGN_TIPS_JA.md) のうち、画面目的（01）、iPhone幅・Safe Area（03）、デザイントークン（04）、状態（05）、アクセシビリティ（06）、自動検証と実機確認の区別（09）を用いる。これは参照ガイドであり、UIの合格を自動保証するものではない。

## Foundation 2-1 の範囲

- `src/app/index.tsx` をホーム画面へ置き換える。
- Day 4、3/30日完了、約10分、一般動詞の現在形を**サンプル値**として表示する。
- 進捗バー、今日のレッスン、英文例、できるようになったことの順に配置する。
- 色・余白を画面内の意味付き定数として管理する。外部UIライブラリやDBを追加しない。
- 「レッスンを始める」は**操作できない準備中の表示**とし、未実装の解説画面へ遷移しない。完成済みのCTAとして扱わない。

## 今回の対象外

- レッスン解説・練習・まとめ・AIヒント・復習・成長記録・設定画面。
- タブナビゲーション、認証、永続化、API通信、実際の進捗更新。
- 実際の学習者データに基づく表示。
