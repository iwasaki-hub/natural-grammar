# Foundation 2-4 — レッスンまとめ画面と学習完了フロー

## 実装
- Day 4の練習3問正解後に `/summary` へ進む。
- まとめに「毎日の習慣を英語で言える」と例文、一般動詞の現在形のルールを表示。
- 「レッスンを完了する」で、ホームのサンプル進捗を 3/30 → 4/30 に変更し、成長記録の文言を更新。
- React Contextを使用し、画面間で完了状態を共有。二重完了しても 5/30 にならない。
- 練習未完了の状態でまとめを直接開いた場合は、練習へ戻す案内を表示。
- iPhoneのSafe Area、スクロール、押しやすいボタン、進捗のアクセシビリティ値に対応。

## 重要な制約
- **完了状態はアプリ起動中のメモリにのみ保存。** Webの再読み込み・アプリ再起動で 3/30 に戻る。
- 認証、Supabase、永続化、AIヒント、他の日の教材は未実装。
- 4/30はDay 4サンプルのデモ進捗であり、実際の学習データではない。
