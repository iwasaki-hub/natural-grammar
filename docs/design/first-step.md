# 今日の一歩

英文法を初めて学ぶ社会人向けのiPhoneアプリ「Natural Grammar」の初期デザイン。アメリカ英語の基礎を、1日約10分、30日間の決まった順序で学ぶ。

## 学習の流れ

| 場面 | 表示と操作 |
| --- | --- |
| ホーム | コース進捗バー、今日のレッスン、「できるようになったこと」の順に表示する。カードに文法テーマと所要時間を載せ、「レッスンを始める」で解説へ進む。 |
| 解説 | 身近なアメリカ英語の例文を、短い日本語の解説と一緒に読む。コースが進むにつれて英語の説明を増やす。 |
| 練習 | 問題を1問ずつ表示し、画面上部で「解説・練習・まとめ」の現在位置を示す。誤答時は短い手がかりを表示し、同じ問題で再挑戦できる。 |
| AIヒント | 練習でつまずいたときに「AIにヒントを聞く」から開く。今の問題について質問できる。画面下から開くパネルを閉じると同じ問題に戻る。 |
| まとめ | 学んだことを「毎日の習慣を英語で言える」などの一文で振り返る。レッスン完了後、コース進捗が例では 3 / 30 から 4 / 30 に進み、この一文が成長記録に残る。 |

### 練習とAIヒントの例

穴埋め問題「I ___ coffee every morning.」で「drinks」を選ぶと、「主語の I に注目してみましょう」と表示する。「なぜ drinks ではないの？」とAIに聞くと、現在形の肯定文では主語が he・she・it などの三人称単数の場合に一般動詞に -s などを付ける、という考え方を示す。

## タブと初期版の方針

- **ホーム** — コース進捗、今日のレッスン、直近の成長記録を表示する。
- **復習** — 練習で間違えた問題を解き直せるようにする。
- **成長記録** — レッスンを通じてできるようになったことを振り返る。
- **設定** — ポップと落ち着いたシンプルの2つの外観を切り替える。掲載モックはポップ版。
- 教材はアプリ用に作成し、日ごとのカリキュラムに沿って提供する。発音練習と音声再生は後の段階で扱う。

この資料は画面と学習導線の設計を記録したもの。掲載画像は静的モックで、解説・まとめ・復習・成長記録・設定の個別画面は文章で示している。
